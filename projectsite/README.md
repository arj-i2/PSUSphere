# PSUSphere

## Description

PSUSphere is a student organization management system for Palawan State University. It allows users to manage student information, academic programs, colleges, organizations, and organization memberships in one centralized system.

## Features

- Manage colleges
- Manage academic programs
- Manage student information
- Manage student organizations
- Manage organization members
- Search students and organizations
- Filter colleges, programs, and organizations
- Track organization membership dates
- Django Admin interface for managing records
